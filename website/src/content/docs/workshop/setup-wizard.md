---

## 第 1 步：说明

确认下载需要一个拥有 Wallpaper Engine 的全球 Steam 账号，并了解浏览 API 与下载服务彼此独立。

## 第 2 步：Steam 登录

向导默认显示二维码。使用 Steam 手机应用扫码并确认即可登录，也可以切换到账户名和密码。二维码会随 Steam 的挑战更新自动重绘，长时间未更新时 Mirage 会自动重建会话，也可以手动点击“刷新二维码”。Steam Guard 需要的邮箱验证码、手机验证码或手机确认会在同一页完成。

登录由随 App 提供的内置服务完成，不需要安装额外组件。刷新令牌保存在 macOS 钥匙串，密码不会保存。

## 第 3 步：完成

登录成功后向导会自动进入完成页。Wallpaper Engine 所有权和具体作品访问权限会在首次下载时由 Steam 验证。

浏览仍依赖 Steam Web API。建议另外配置自己的 [Steam Web API Key](/workshop/api-key/)，避免共享 Key 繁忙。
